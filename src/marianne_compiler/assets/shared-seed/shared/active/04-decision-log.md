# Decision Log

Use this for decisions that change another agent's work.

## Decisions

| id | owner | decision | reason | impacts | date |
| --- | --- | --- | --- | --- | --- |
| starter-D-000 | unowned | Replace this starter row with the first real decision. | | | |

## Decision Format

| {agent}-D-001 | {agent} | State the decision that changes another agent's work. | Evidence-backed reason. | impacted surfaces | YYYY-MM-DD |

The format row uses braces as placeholders. Replace them before writing to the
Decisions table; do not copy placeholder rows as live decisions.

Do not hide unresolved controversy. If there is dissent, record it in
`reason` or add a follow-up task in the task board.
Use owner-scoped ids (`{agent}-D-001`, `{agent}-D-002`, ...), not global
incrementing ids.
